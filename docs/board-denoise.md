# 开发板实时降噪 v1

## 当前用途

`mic-denoise` 固件在 ESP32-S3 上连续处理 INMP441 采样。电脑只接收已经处理的 PCM，并保存 WAV。
这是 COM 串口开发验证版，不是标准 USB Audio Class 固件；暂时不能用它直接接手机相机录音。

32 kHz、单声道；512 点 sqrt-Hann STFT，256 点步长，每步 8 ms，算法重叠延迟 256 个样本（8 ms）。加上采集、串口和主机的总延迟另计。

实时算法使用因果噪声跟踪、最多 6 dB 稳态频谱衰减、最多 4 dB 局部短时异常衰减和窄频峰保护，并平滑增益。
没有人声模型、固定高通、硬噪声门、自动增益或可靠的距离识别。首次启动的背景估计可能受到当时声音的影响。
启动后建议留几秒环境声再录制。噪声变化较大时效果需要重新验证。

## 与电脑试验的区别

电脑版使用全段低分位噪声估计和包含未来帧的时间统计；实时固件只能参考已到达的数据，窗口更短，局部处理更保守，不能保证与电脑 MP3 相同效果。
窄频峰保护有助于保留音色，也可能保留尖锐吱声；没有实现无损去掉与目标声重叠的摩擦声。

## 使用与回退

重新打开 `Start-Recorder.cmd`。勾选“开发板实时降噪”后录音，取消勾选录制原声旁路。
每次接收的 WAV 是设备输出：启用降噪时已处理，不应再称为未经处理的麦克风原声。`-listen.wav` 只在此基础上加试听增益。
报告保存固件版本、模式、处理时间、I²S 缓冲溢出及读错误；捕获异常会在窗口提示。分开录制的两次素材不是完全相同输入。

```powershell
# 烧录实时降噪固件
.\.venv\Scripts\python.exe -m platformio run -d firmware/mic-test -e mic-denoise -t upload --upload-port COM9
# 回退到旧录音固件（源代码保留，重新编译烧录）
.\.venv\Scripts\python.exe -m platformio run -d firmware/mic-test -e mic-record -t upload --upload-port COM9
# 同一输入经过真实开发板的数字回放验证
.\.venv\Scripts\python.exe tools/board_dsp_test.py --case
```

工厂完整 Flash 备份仍保存在 `hardware/backups/factory-20261021.bin`。
`board_dsp_test.py --case` 将固定测试案例下混为单声道并重采样为 32 kHz，分块送入真实开发板，再收回处理结果；不是电脑模拟，也不是扬声器播放后重新录音。
脚本核对旁路重建误差、已知噪声片段变化、目标正弦幅度和每步处理耗时。实际录音效果仍需试听。

## 2026-10-22 实测

初版现场捕获曾出现缓冲溢出：10 秒音频耗时约 13.14 秒，溢出 386 次，该录音保留并标记 `capture_valid=false`，不能作为合格结果。
将频率邻域内重复除法改为预计算及累积和后，现场捕获 320000 帧约耗时 10.006 秒，DSP 最慢 2293 微秒，溢出和读错误均为 0。
优化后合成信号板上回放：原声旁路误差 0 LSB，DSP 最慢约 2353 微秒；已知噪声片段约下降 0.86 dB，目标音调约变化 -0.010 dB。当前策略较保守，这不是椅子摩擦声去除效果证明。
最终优化版二进制及哈希保存在 `hardware/backups/realtime-denoise-v1-optimized/`。

## 固定输出增益与窄带底噪处理

当前 v1.3 按用户要求将固定输出增益从 3 倍提高到 **5 倍**（相对原幅度约 +13.98 dB，相比 3 倍再增加约 4.44 dB），原声与降噪模式均生效，仍作 16-bit 饱和截断。大声输入仍可能削波，底噪也会放大；不会修改手机 App 或生成额外视频。以下为此前三倍增益版本的测量记录。

固件输出在 DSP 后固定乘以 3（约 +9.54 dB），原声与降噪模式均生效。转换为 16-bit PCM 前作饱和截断，避免整数回绕；过大的输入仍会削波，数字增益不能改善麦克风自身的信噪比。Android 软件不变，也不会因此生成额外编辑视频。

一次安静现场采样发现 125 Hz、250 Hz 窄带峰值，但无法据此确认是供电、接线还是环境声。板端降噪模式新增两个 Q=60 窄带滤波器，以 50% 原声混合将中心衰减限制在约 6 dB；关闭降噪时不应用这些滤波，仍保留 3 倍输出。此配置针对当前原型的实测峰值，不是通用电流噪声识别器；恰好位于中心频率的乐音也会受到影响。共享的 Android DSP 头文件未修改。

同一段 10 秒样本真实板端回放对比：125 Hz 降约 5.79 dB、250 Hz 降约 6.01 dB，500/1000 Hz 变化小于 0.002 dB；整段 RMS 降约 1.35 dB。板端最大处理时间 2613 微秒，低于 8000 微秒步长。正负超幅测试与预期三倍饱和输出误差 0 LSB。噪声来源与手机连接状态下的实际听感仍需进一步验证。
